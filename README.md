# Pizza BFO Ontology

A pizza ontology aligned to BFO 2020 - the BFO that NFDIcore 3.0.5 builds on - and made from BFO and NFDIcore design patterns. It holds no individuals: its instance data is a separate knowledge graph built from ROBOT templates.

IRI: `https://ebrahimnorouzi.github.io/pizza-bfo/pizzabfo.owl`

## Editing

Open `src/ontology/pizzabfo-edit.owl` in Protege. That is the file you
edit; `pizzabfo.owl` is generated by the build.

## Building

From `src/ontology`, with `make` and ROBOT on your PATH:

```
make all        # reason, then report - and what a bare `make` runs
make reason     # classify with ELK into pizzabfo.owl
make report     # ROBOT quality report -> report.tsv
make sparql_test  # run every check in ../sparql over the edit file
make validate_profile  # fail if the ontology has left OWL 2 DL
make test       # what CI runs: reason, report and sparql_test
make prepare_release  # test, then a dated, version-stamped release
make clean      # delete the generated files
```

Custom targets go in `pizzabfo.Makefile`, which the build includes and
never overwrites. `Makefile` itself is generated - do not edit it.
